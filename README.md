# 老回怒闯三星洞

Demo 1.1 · 补充原始资料版本

## 作品说明

这个作品出于个人兴趣和学习而制作，也是一次使用 AI 辅助创作的尝试，不以商业运营为目的，提供免费下载体验。

作品借用了一起电子消费品质量事件的背景，但不是纪实还原，其中包含大量虚构情节、编写的对白和艺术加工。玩家选择产生的协议、道歉及不同结局，不代表现实事件曾按这些方式发生。

**了解事件原型，请参阅当事人老回自己的记录，不要把本作品的剧情当作事实依据：**

[老回的事件自述汇总（知乎专栏）](https://www.zhihu.com/column/husky0708)

原始录像作为单独的资料回看提供，应与虚构剧情分开理解。本作品不代表任何品牌、机构或媒体的背书。

## 下载和开始

**[下载完整运行包（约 333 MB）](https://github.com/youyuguyouyugu-coder/laohui-demo/releases/download/demo-1.1/laohui-demo-1.1-full.zip)**

也可以进入本项目的 **[Releases（版本发布）](https://github.com/youyuguyouyugu-coder/laohui-demo/releases)** 页面，找到 **Demo 1.1 · 补充原始资料版本**，下载：

文件约333 MB，包含全部六组可回看的原始录像。

1. 完整解压 ZIP，不要只取出其中一个文件。
2. 打开解压后根目录的 `index.html`。
3. 推荐先使用电脑浏览器体验；原始录像可以暂停、关闭或跳过。

如果浏览器限制本地文件播放，请按照包内 `README.txt` 的说明使用本机运行方式。无需安装单独的游戏客户端。

## 这个版本包含什么

- 四条完整结局，以及一条较早结束的赔偿支线。
- 六组可自行选择播放的原始资料：CNN 报道、手机冒烟现场、携记者首次到总部、交涉与复印报告、泰尔检测、老回直播。
- 完整的现有剧情、画面、音乐和制作名单；早期赔偿短结局保持简短收尾。

本版已移除独立预览页和开发跳转入口。存档保存在当前浏览器本地，不会上传到服务器。

本仓库首页用于项目介绍和下载指引。完整体验请使用 Releases 中的完整运行包。
